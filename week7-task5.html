1. Objective & Problem Statement

Problem Being Addressed: Modern smart environments demand intelligent edge decision-making combined with centralized cloud auditing. Simple remote switches (Tasks 1-3) lack autonomous environmental awareness, while transient sensor displays lack historical persistence. Building managers and researchers need an integrated IoT platform that can autonomously control lighting based on ambient daylight, record high-resolution timestamped telemetry for energy auditing, and allow non-technical operators to export historical records into analytical spreadsheets.

Comprehensive System Objective: Integrate an ESP32 microcontroller with a DHT11 temperature/humidity sensor, an LDR analog voltage divider, and a 5V SPDT relay module to achieve:

  • Dual-mode appliance control: Manual dashboard override vs Autonomous threshold-driven lighting.
  • Real-time telemetry streaming to Google Firebase Realtime Database.
  • Immutable timestamped logging of environmental and actuator states under /logs.
  • Dynamic visualization via multi-series line graphs and one-click verified CSV data export.

4. Operating Modes & Automatic Lighting Logic

The system implements two strictly isolated operating modes stored under /control/mode:

  • MANUAL Mode: The ESP32 reads /control/bulb from Firebase. Any toggle made by the authenticated user (arch@gmail.com) on the dashboard immediately sets the relay output. Automatic threshold logic is bypassed.
  • AUTOMATIC Mode: The ESP32 autonomously executes closed-loop threshold logic. The dashboard manual toggle button is visually disabled to prevent race conditions.

LDR Threshold Calibration Method

The Light Dependent Resistor (LDR) forms a voltage divider with a 10 kΩ precision resistor. In darkness, the LDR resistance skyrockets to >100 kΩ, pulling the voltage at GPIO 34 towards 3.3V (ADC count ~4095). Under intense ambient illumination, resistance drops below 1 kΩ, dropping the voltage towards 0V.

Environmental Condition Observed Raw ADC Count (0–4095) Equivalent Voltage Automated Lighting Decision
Direct Torch / Sunlight 180 – 550 0.14V – 0.44V Bulb remains OFF (Sufficient ambient daylight)
Standard Lab Ambient Lighting 1,400 – 2,200 1.12V – 1.77V Bulb remains OFF (No artificial light needed)
Dim Twilight / Evening Shade 3,100 – 3,650 2.50V – 2.94V Bulb remains OFF (Pre-threshold zone)
Dark / Covered Sensor (Observed in Test) 4,095 (Max Dark) 3.30V Bulb Switched ON (LDR > 3800 Threshold Reached)
Formal Switching Algorithm:
if (currentMode == "auto") {
  if (ldrRaw > 3800) { digitalWrite(RELAY_PIN, LOW); bulbState = true; }
  else { digitalWrite(RELAY_PIN, HIGH); bulbState = false; }
}

10. Problems Encountered & Technical Solutions

Problem Encountered Root Cause Implemented Resolution
LDR ADC counts oscillated wildly near 3800 Minor electrical noise and subtle shadow variations caused rapid relay chatter. Introduced a 100-count hysteresis band (ON at >3800, OFF at <3700) and software averaging.
Timestamps showed 1970 Epoch in Firebase ESP32 RTC was uninitialized before the first telemetry write. Integrated NTP time synchronization (pool.ntp.org) with IST GMT+5:30 offset before initiating writes.
Downloaded CSV corrupted special characters (°C) Browser text encoder omitted explicit UTF-8 BOM encoding. Added charset=utf-8 MIME prefix to client-side data URI stream.
Firebase write latency blocked sensor loop Synchronous blocking calls held the execution thread. Decoupled sensor reads from cloud writes using a non-blocking 3-second millis() timer.

11. Prototype Limitations & Future Scope

Current Prototype Limitations

  • Sensor Accuracy: DHT11 has limited range (0–50°C) and ±2°C accuracy compared to industrial DHT22 / BME280 sensors.
  • ADC Non-Linearity: ESP32 ADC1 exhibits non-linear response near 0V and 3.3V, requiring piecewise calibration.
  • Network Dependency: If Wi-Fi disconnects, the device cannot log historical records unless local EEPROM/SD buffering is present.

Proposed Future Improvements

  • Edge ML Intelligence: Implement TinyML on ESP32 to predict room occupancy and adjust lighting proactively.
  • Offline Flash Storage: Integrate LittleFS or SPIFFS to store telemetry locally during network outages and sync on reconnect.
  • Over-The-Air (OTA) Updates: Enable remote firmware flashing over Wi-Fi without requiring USB tethering.
